# World geographic base

Natural Earth Admin 0 Countries at 1:110m, public domain.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson

Terms: https://www.naturalearthdata.com/about/terms-of-use/

The GeoJSON is bundled locally so the point map does not contact a tile service or require an API key. This is a low resolution geographic background, not a legal statement about boundaries. Plot positions come from actual latitude/longitude dataset columns; region names are never silently geocoded.
